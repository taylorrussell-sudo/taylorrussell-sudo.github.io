Privacy Policy

Last updated: November 4, 2026

About this application

Russell Pi Google Access is a private household application operated using a Raspberry Pi.

Google data accessed

The application is intended to read authorized Google Calendar events and create encrypted configuration backups in Google Drive.

How data is used

Calendar information is used to display a household calendar. Google Drive is used to store and retrieve backups when configured.

Storage and security

Application credentials and calendar data are handled locally on the Raspberry Pi. Backup files will be encrypted before upload.

Data sharing

Google user data is not sold or used for advertising. The application does not intentionally share Google user data with third parties other than services required for its operation.

Data retention and control

Local application data may be deleted by the operator. Backup retention will be managed through the backup system when configured. Google access can be revoked through Google Account security settings.

Contact

For questions, contact the application operator through the GitHub profile: taylorrussell-sudo.
